# Registros de decisiones de arquitectura (ADR)

Cada decisión relevante se documenta en un archivo numerado con el formato
`NNNN-titulo-corto.md`. Los ADR no se editan una vez aceptados; si una decisión cambia,
se crea un nuevo ADR que reemplaza al anterior y se anota en ambos.
